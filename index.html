Deze sectie toont je dagelijkse bereik, profielweergaven, interacties en je best presterende berichten. Daarvoor heeft je Instagram-token het recht instagram_business_manage_insights nodig — het huidige token heeft dat (nog) niet. Maak het token opnieuw aan met dat recht en zet het klaar met scripts/set-token.js (zie de README). Zodra de dagelijkse run insights binnenhaalt, verschijnen ze hier vanzelf.

Naamlijsten bijwerken
Normaal hoef je hier niets te doen: de agent op je PC vraagt elke 4 dagen automatisch een export aan en werkt de lijst bij. Dit vak is het vangnet — bijvoorbeeld als je sessie verlopen is of je tussendoor een verse meting wil. Vraag je export aan via Instagram → Instellingen → "Je informatie downloaden" → Volgers en gevolgde accounts, en sleep de .zip hieronder. Werkt ook vanaf je telefoon.

Nodig: een fine-grained Personal Access Token met Contents: Read and write op alleen de repo roelgeelen/ig-dashboard. Aanmaken via github.com/settings/personal-access-tokens/new.
Aantallen worden dagelijks automatisch opgehaald via de officiële Instagram API. Naamlijsten worden elke 4 dagen automatisch bijgewerkt door de agent op je PC — vaker staat Instagram niet toe. Alle data is versleuteld met je passphrase.
